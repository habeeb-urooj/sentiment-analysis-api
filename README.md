# 🤖 AI Sentiment Analyzer

An end-to-end AI-powered Sentiment Analysis web application built using Machine Learning and FastAPI. The application predicts whether a user review is **Positive** or **Negative** through a simple and interactive web interface.

---

## 📌 Features

- ✅ Sentiment Analysis using Machine Learning
- ✅ TF-IDF Vectorization
- ✅ FastAPI REST API
- ✅ Interactive HTML/CSS/JavaScript Frontend
- ✅ Real-time Predictions
- ✅ Clean and Responsive UI
- ✅ Easy Deployment

---

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-sentiment-analyzer.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
uvicorn data.api.main:app --reload
```

Open your browser

```
http://127.0.0.1:8000
```
